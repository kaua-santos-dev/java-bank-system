# Java Bank System 🏦

Sistema bancário simples feito em Java, simulando operações de um banco no terminal.

## 🚀 Funcionalidades
- Criar conta bancária
- Consultar saldo
- Depositar valores
- Sacar valores
- Transferir entre contas

## 🛠️ Tecnologias
- Java 17
- Programação Orientada a Objetos (POO)
- Encapsulamento e Classes

## ▶️ Como rodar
1. Clone o repositório:
`git clone https://github.com/kaua-santos-dev/java-bank-system.git`
2. Abra no IntelliJ IDEA
3. Rode a classe `Main.java`
